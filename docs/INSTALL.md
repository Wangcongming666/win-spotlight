# FocusSearch 便携版使用说明

1. 下载 `FocusSearch-版本-windows-portable.zip` 并解压到任意可写目录。
2. 双击 `FocusSearch.exe`。无需编译源码、安装 Node.js 或安装 .NET SDK。
3. 按 `Alt + Space` 打开聚焦搜索。右下角通知区域的蓝色放大镜是程序图标；如果被系统折叠，可点击托盘箭头查看。
4. 右键该图标 → 设置，可以切换组合/分离模式、修改快捷键、关闭动画或启用开机启动。
5. 分离模式下使用 `Alt + A` 打开全屏应用网格。滚轮翻页、方向键选择，Enter 启动，Esc 收起。
6. 右键托盘 → 退出可以完全退出并释放快捷键。

适用于 Windows 10/11 x64，需要系统已安装 .NET Framework 4.8 或 4.8.1。便携版可执行文件未做商业代码签名。

文件搜索优先使用 Windows Search 的已有索引。接口不可用时只搜索桌面、文档和 Downloads 的有限范围，不会扫描整块磁盘。

设置保存在 `%LOCALAPPDATA%\FocusSearch`。更新版本前先退出旧程序，再替换 exe。删除程序前先取消开机启动。

程序不联网，不上传搜索数据；玻璃背景仅在唤起时读取当前屏幕覆盖区域并生成临时模糊图像，收起后释放，不保存屏幕内容。
