> 面向 Windows 的轻量级桌面搜索与应用启动器。通过全局快捷键搜索应用、文件夹和文件，以独立应用网格浏览并启动软件。

FocusSearch 借鉴 macOS Spotlight 与 Launchpad 的交互方式，提供紧凑搜索栏、分类搜索、全屏应用网格和玻璃质感界面。程序基于 Windows 桌面技术运行，无需额外的 Web 运行环境或后台服务。

本文介绍 `main` 分支当前源码的功能。已发布版本的功能以对应版本的发布说明为准，各版本变更见[更新记录](CHANGELOG.md)。

## 产品定位

FocusSearch 将常用软件启动和本机文件检索集中到一个键盘入口，适用于希望减少桌面切换、通过名称或缩写快速定位项目的 Windows 用户。

应用网格只展示软件；文件、文件夹和网页快捷方式在输入关键词进行搜索时显示。文件检索使用系统已有索引，并在接口不可用时提供有限范围回退，不承担全盘索引或文件内容搜索功能。

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 全局快捷搜索 | 默认按 Alt + Space 唤起搜索栏，再次按下可收起同一视图 |
| 独立应用网格 | 默认按 Alt + A 打开无搜索栏的全屏软件列表，支持翻页和键盘导航 |
| 分类搜索 | 提供「应用 / 文件夹 / 全部 / 文件」四种范围，可悬浮或点击切换 |
| 名称与路径匹配 | 支持应用名称、路径片段、英文单词缩写和常用汉字拼音首字母 |
| 类型优先排序 | 综合结果按「应用程序 → 文件夹 → 文件 → 网页入口」排序 |
| 软件入口识别 | 解析快捷方式实际目标，排除文档、文件夹、失效程序入口与子目录构建产物 |
| 自动刷新索引 | 监听开始菜单和桌面目录变化，自动更新应用入口 |
| 本机文件检索 | 优先查询 Windows Search；接口不可用时搜索桌面、文档和下载目录 |
| 右键操作 | 支持打开项目、打开所在位置并选中项目、复制路径 |
| 使用频率排序 | 本地记录成功打开次数，参与应用浏览和同类搜索结果排序 |
| 自定义快捷键 | 可修改搜索与应用网格快捷键，检测冲突并保留原配置 |
| 托盘管理 | 提供显示搜索、应用程序、设置、关于及退出入口 |
| 外观与动画 | 搜索界面跟随系统应用深浅色设置，支持磨砂背景、过渡动画与悬停反馈 |
| 本地运行 | 配置和历史存储在本机，支持单实例、后台启动及登录时自动启动 |

## 快速开始

1. 打开 [GitHub Releases](https://github.com/Wangcongming666/win-spotlight/releases)，下载 `FocusSearch-<版本>-windows-portable.zip`。
2. 将压缩包完整解压到一个可写目录。
3. 双击 `FocusSearch.exe`。程序启动后显示搜索栏，并在 Windows 通知区域驻留。
4. 按 Alt + Space 搜索应用或本机文件；按 Alt + A 浏览应用网格。
5. 右键通知区域的蓝色放大镜图标，打开设置或退出程序。

通知区域图标可能位于隐藏图标列表中。完整退出请使用托盘菜单的「退出」；收起搜索栏不会终止后台进程。

发布资产提供 `SHA256SUMS.txt`，可与下载文件的 SHA-256 值进行核对：

```powershell
Get-FileHash -LiteralPath ".\FocusSearch-<版本>-windows-portable.zip" -Algorithm SHA256
```

### 更新与移除

更新前先从托盘退出旧版本，再替换程序文件并重新启动。配置与使用历史独立于程序目录，替换可执行文件不会主动清除这些数据。

移除前，在设置中取消「登录 Windows 时自动启动」，从托盘退出后删除程序目录。如需同时清除配置与历史，可另行删除 `%LOCALAPPDATA%\FocusSearch`。

## 操作指南

### 搜索面板

搜索面板初始显示单行胶囊搜索栏。输入关键词后展开结果列表，应用结果先返回，文件检索在后台执行；继续输入会取消已过时的查询，避免旧结果覆盖当前输入。

将鼠标移至搜索栏右侧可展开分类按钮：

| 分类 | 行为 |
| --- | --- |
| 应用 | 仅返回软件；无关键词时可浏览应用网格预览 |
| 文件夹 | 返回匹配的目录和文件夹快捷方式 |
| 全部 | 合并应用、文件夹、文件及已索引网页入口 |
| 文件 | 返回匹配的文件和文档快捷方式 |

鼠标悬浮或点击分类按钮均可切换范围。应用预览在鼠标离开预览区域后收起；已有关键词的结果列表保持展开，便于选择和打开。

### 应用网格

Alt + A 打开独立全屏应用网格。网格仅包含软件入口，按使用次数优先展示常用应用，同等情况下按名称排列。应用预览与全屏网格在正常宽度下均为每行六个应用，极窄窗口按可用宽度减少列数。

鼠标滚轮或 Page Up / Page Down 可翻页；方向键移动选择。单击选中，双击启动，也可按 Enter 打开选中应用。网格中不提供文件浏览或图标拖拽整理。

### 快捷键与鼠标操作

| 操作 | 默认方式 |
| --- | --- |
| 显示或收起搜索面板 | Alt + Space |
| 显示或收起独立应用网格 | Alt + A，需启用应用网格 |
| 展开分类并进入键盘选择 | F6，随后使用 Tab / Shift + Tab 移动焦点 |
| 在结果列表中移动选择 | ↑ / ↓ |
| 在应用网格中移动选择 | ↑ / ↓ / ← / → |
| 应用网格翻页 | 滚轮、Page Up / Page Down |
| 打开选中项目 | Enter 或双击 |
| 收起分类按钮 | 分类展开时按 Esc |
| 收起面板 | 分类收起后按 Esc，或点击底部收起按钮 |
| 打开项目操作菜单 | 右键结果或应用图标 |
| 从托盘打开搜索 | 双击托盘图标，或右键选择「显示搜索」 |

搜索与网格之间可直接使用对应全局快捷键切换。修改后的快捷键会同步显示在托盘菜单中。

### 项目右键菜单

| 操作 | 说明 |
| --- | --- |
| 打开 | 使用系统默认关联或程序入口打开选中项目 |
| 打开所在位置 | 打开资源管理器并选中项目；快捷方式定位到快捷方式本身所在目录 |
| 复制路径 | 将当前项目路径复制到剪贴板 |

「打开所在位置」通过 Windows 原生接口执行，确认成功后才收起面板；失败或资源管理器无响应时保留面板并显示原因。网页类型入口不提供此操作。

应用启动优先使用系统 Shell。可执行程序快捷方式的 Shell 启动失败时，程序会尝试保留目标、参数与工作目录直接启动；打开失败时在面板内显示原因。

## 搜索规则与索引范围

### 应用匹配

应用搜索支持大小写无关匹配、名称与路径片段、英文缩写、常用汉字拼音首字母和全角字符归一化。

| 输入示例 | 匹配示例 |
| --- | --- |
| 微信 / wx | 微信 |
| 抖音 / dy | 抖音 |
| bdwp | 百度网盘 |
| vsc | Visual Studio Code |
| 应用安装路径片段 | 路径中包含该片段的软件入口 |

示例对应的软件需要先出现在应用索引中。中文首字母依据常用汉字编码区间生成，生僻字、多音字和特殊命名可能需要输入原名。

### 结果排序

综合搜索先按类型排列：**应用程序 → 文件夹 → 文件 → 网页入口**。同一类型内再按匹配得分和本地使用次数排序，名称用于同分排序。

名称精确匹配、前缀和连续字符匹配优先于缩写或稀疏字符匹配。类型优先级不会被文件匹配程度或使用次数覆盖。例如输入 wx 时，微信会显示在 WXWork、WXWorkCefCache 等目录之前。

搜索列表最多显示 8 条结果，按路径去重。无关键词时不执行文件检索；应用分类也不会查询文件提供程序。Windows Search 和回退目录检索在输入至少 2 个字符后启动，已索引的应用及快捷方式可以更早返回。

### 应用索引

索引来源为当前用户与公共开始菜单、当前用户与公共桌面。支持 `.lnk`、`.appref-ms`、根目录中的 `.exe` 以及用于综合搜索的 `.url` 入口。

- .lnk 按实际目标分类：存在的程序或程序启动脚本归为应用，文档与目录分别归为文件和文件夹。
- 指向不存在程序、无法解析的快捷方式、帮助文档和文件夹入口不作为软件展示。
- 可解析快捷方式按目标、启动参数和工作目录去重；不同启动参数的入口可能分别保留。
- 子目录收集快捷方式与 ClickOnce 入口，跳过其中的独立 .exe，避免把项目构建产物逐个加入网格。
- 索引扫描不递归进入目录重解析点，降低循环遍历风险。

便携软件未出现在网格中时，可在桌面或开始菜单中为其创建快捷方式。程序不会扫描所有磁盘寻找可执行文件，也不单独枚举没有受支持入口的商店应用。

### 文件与文件夹检索

优先查询 Windows Search 已有索引，按文件名及路径检索。FocusSearch 不新建系统文件索引，也不会自动调整 Windows 的索引目录。

接口不可用时，使用有边界的本地目录检索：

| 项目 | 回退范围 |
| --- | --- |
| 目录 | 当前用户桌面、文档、用户目录下的 Downloads |
| 文件递归深度 | 根目录及其下两级子目录 |
| 文件检查预算 | 最多 5,000 个文件 |
| 扫描时间预算 | 250 ms |
| 文件候选数量 | 每次最多 32 条，再参与综合结果排序 |

回退状态会在面板底部显示「文件搜索：桌面 / 文档 / 下载（有限范围）」。预算限制、文件访问权限和系统索引范围都可能影响结果完整性。

## 设置与个性化

右键托盘图标选择「设置…」，修改后点击「保存」生效。取消关闭不会保存改动。

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 搜索框与应用程序一起显示 | 开启 | 保留组合显示配置；当前搜索面板初始仍为紧凑栏，应用预览按需展开 |
| 启用应用程序网格 | 开启 | 控制应用预览、独立网格入口及对应快捷键是否可用 |
| 失去焦点时自动收起 | 开启 | 切换到其他窗口时收起面板；项目菜单或文件定位处理中保留面板 |
| 启用展开与收起动画 | 开启 | 控制窗口和网格过渡；同时尊重系统动画设置 |
| 启用本机文件搜索 | 开启 | 控制 Windows Search 与回退目录查询；关闭后仍可检索已索引快捷方式 |
| 登录 Windows 时自动启动 | 关闭 | 在当前用户的登录启动项中注册程序，以后台模式启动 |
| 搜索面板快捷键 | Alt + Space | 点击输入框后按下所需组合键 |
| 独立应用网格快捷键 | Alt + A | 启用网格时可配置 |

快捷键输入支持 Alt、Ctrl、Shift 与一个普通按键组合。保存时会检测两个入口是否冲突以及快捷键是否被其他程序占用；失败时提示原因，并保留原有快捷键配置。

## 界面与交互设计

搜索面板采用胶囊输入栏、按需展开的圆形分类、玻璃背景和圆角结果列表。右侧四个分类按钮依次淡入、缩放并轻微移动，离开时平滑收起；快速移入移出会从当前进度接续，关闭动画时立即切换。应用网格使用分页图标布局，项目菜单使用统一的自绘圆角样式。

搜索界面在每次唤起时读取 Windows 的应用深浅色设置。字体按已安装情况选择 SF Pro、Segoe UI 或 Microsoft YaHei UI，并对高对比度环境使用系统颜色。托盘菜单、设置和关于窗口采用各自的桌面控件布局，不保证与搜索面板完全相同的主题呈现。

后台图标提取、相邻页预加载和有界缓存减少翻页过程中的等待；滚轮事件合并降低重复处理。动画可以关闭，程序也会检查系统动画偏好。

## 隐私与本地数据

FocusSearch 的索引、搜索、配置和使用记录在本机处理，不向项目服务器上传搜索数据，也不内置云同步、遥测或自动更新请求。打开网页快捷方式或其他应用后，其网络行为由对应程序负责。

| 文件 | 位置与用途 |
| --- | --- |
| `settings.xml` | `%LOCALAPPDATA%\FocusSearch`，保存设置和快捷键 |
| `history.xml` | 同一目录，保存项目路径、成功打开次数及最近打开时间 |
| `errors.log` | 同一目录，记录配置和历史读写异常 |

面板唤起时读取覆盖的屏幕区域，生成内存中的模糊背景；收起后释放，不持续截屏，也不将屏幕内容保存到文件。运行时配置不会写入源码仓库或便携程序目录。

程序启动时会检查当前进程的 Windows 必需环境变量，仅补齐缺失项以兼容部分启动环境；不会改写用户或系统级环境变量。

## 开发与测试

### 获取源码

```powershell
git clone https://github.com/Wangcongming666/win-spotlight.git
cd win-spotlight
```

### 常用命令

在仓库根目录执行。构建脚本使用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，需要该系统编译器路径可用。

```powershell
# 编译程序，输出 build\FocusSearch.exe
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

# 编译并执行完整测试
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test

# 构建并启动，也可双击「启动.cmd」
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1

# 后台启动或请求运行中的实例退出
.\build\FocusSearch.exe --hidden
.\build\FocusSearch.exe --quit
```

也可将命令中的 powershell 替换为 pwsh。重新编译前请退出从 build 目录运行的程序，避免输出文件被占用。重复启动通过单实例机制唤起现有程序。

### 测试范围

测试覆盖匹配与缩写、类型排序、索引分类和去重、查询取消、目录回退、设置与历史、热键冲突、键盘和鼠标操作、右键菜单、文件定位成功与失败反馈、应用启动参数、背景效果及图标缓存。

```powershell
# 完整测试后，执行窗口、布局与全局热键冒烟测试

# 检查翻页事件处理性能
```

界面测试需要交互式 Windows 桌面，会显示窗口并将验证截图保存到 build。截图不纳入发布包。性能测试测量事件处理耗时，不代表图标全部加载时间或实际渲染帧率。

### GitHub Actions

推送到 main / master 或手动触发[发布工作流](https://github.com/Wangcongming666/win-spotlight/actions/workflows/release.yml)，会依次执行构建、测试、打包、上传 Actions 构建产物及 Release 发布。

版本号取自 `src/AssemblyInfo.cs`。工作流不会覆盖已存在的同版本 Release；发布新版本需先更新程序集版本与变更记录。若版本号未变，本次构建可从对应 Actions 运行的构建产物获取，已有 Release 资产保持原样。发布需要仓库允许工作流使用 contents: write 权限。

## 常见问题

### 快捷键没有反应

确认程序正在通知区域驻留。检查应用网格是否已启用，再通过托盘设置更换被占用的组合键。注册失败时程序会提示，修改失败不会替换原有配置。

### 应用没有出现在网格中

确认桌面或开始菜单中存在有效程序快捷方式。便携软件可手动创建快捷方式；仅存在于项目子目录的 .exe、失效快捷方式、文档与目录入口不会作为软件展示。

### 文件搜索不到，或提示有限范围

输入至少 2 个字符，并确认本机文件搜索已开启。结果范围取决于 Windows Search 索引；显示有限范围提示时，仅在桌面、文档和下载目录内按预算搜索。其他磁盘、未索引路径及超出递归范围的文件可能无法返回。

### 拼音缩写没有匹配到应用

先确认应用已进入索引，再尝试原名或名称中的连续字符。生僻字、多音字和与程序名称不一致的缩写不保证匹配。

### 打开项目或所在位置失败

查看面板底部的错误提示，并检查项目是否已移动、程序是否仍安装、文件是否具有访问权限，以及资源管理器是否响应。快捷方式的「打开所在位置」定位到入口文件，而非自动跳转到其程序安装目录。

### 新提交已推送，但下载版本没有变化

推送源码不等于创建新的版本号。已有同版本 Release 不会被覆盖；检查工作流结果并下载该次 Actions 构建产物，或在更新版本号后发布新版本。

## 已知限制

- 文件检索不提供内容全文搜索、全盘扫描或独立后台索引服务。
- 综合搜索最多显示 8 条结果，回退目录检索受到范围、深度、数量与时间预算限制。
- 应用发现依赖受支持的桌面与开始菜单入口，不覆盖所有商店应用或磁盘上的程序。
- 暂不提供类似 macOS 的软件类别分组、图标拖拽排序、自定义应用文件夹或云同步。
- 不同 Windows 版本、主题、字体、DPI 与高对比度设置可能影响玻璃效果和布局呈现。
- 可执行文件目前没有商业代码签名；发布资产和完整性校验以仓库 Releases 提供的文件为准。
