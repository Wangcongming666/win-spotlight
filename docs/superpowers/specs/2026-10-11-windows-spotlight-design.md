# Windows 聚焦搜索工具设计规格

## 目标

在 Windows 上实现一个轻量、可长期后台驻留的聚焦搜索和应用启动工具。用户按下 `Alt + Space` 后，可通过键盘快速搜索并启动本机应用、快捷方式和文件，也可通过类似 macOS Launchpad 的应用网格浏览和启动程序。程序不联网、不上传索引数据，不依赖第三方运行库。

## 技术方案

- 语言：C#。
- UI：Windows Forms，配合 Win32 API 实现全局快捷键、无边框窗口、前台激活和系统图标读取。
- 运行时：Windows 自带的 .NET Framework 4.8。
- 构建：调用系统自带的 C# 编译器，输出单个可执行文件；不使用 NuGet、Node.js、Electron 或 WebView。
- 目标平台：Windows 10/11 x64；程序以 AnyCPU 构建并优先以 64 位运行。

## 产品行为

### 唤起与关闭

- 启动时注册全局快捷键 `Alt + Space`。
- 快捷键按下后，搜索窗口在当前工作显示器上方居中显示并立即聚焦输入框。
- 再次按下快捷键、按 `Esc` 或窗口失去焦点时隐藏窗口，不退出进程。
- 注册失败时显示清晰错误信息，并允许从托盘菜单退出。

### 搜索窗口

- 无标题栏、圆角、柔和阴影和半透明玻璃背景，采用接近 macOS Spotlight 的紧凑布局，同时使用 Windows 系统字体和原生文件图标。
- 玻璃效果优先使用 Windows 11 的系统背板材质；不可用时回退到带透明度的纯色背景，保证兼容性和性能。
- 窗口包含搜索输入框和结果区域；输入查询后显示应用和文件结果。
- 键盘操作：上下方向键切换，`Enter` 打开，`Esc` 隐藏。
- 鼠标可选择和双击结果，但完整流程无需鼠标。

### 应用程序网格

- 提供类似 macOS Launchpad 的应用程序视图，使用大尺寸原生应用图标、名称和规则网格布局。
- 支持滚轮、触控板和键盘翻页；支持方向键移动焦点，`Enter` 启动，`Esc` 关闭。
- 图标按常用程度和名称排序；第一版不提供用户自定义文件夹和拖拽重排。
- 网格使用按需图标加载和有界缓存，避免一次性解码全部图标。
- 提供两种显示方式：
  - 组合模式：`Alt + Space` 打开玻璃面板，顶部显示搜索框，空查询时下方显示应用网格，输入后切换为搜索结果。
  - 分离模式：`Alt + Space` 只打开 Spotlight 风格长条搜索框；应用网格以独立的全屏玻璃面板显示。
- 组合模式为默认值。分离模式下，独立应用网格使用可配置快捷键，默认为 `Alt + A`。

### 设置

- 托盘菜单提供“设置”，打开轻量原生设置窗口。
- 可选择组合模式或分离模式，并即时应用。
- 可启用或关闭应用网格、文件搜索、开机启动和失焦自动隐藏。
- 可修改搜索快捷键与独立应用网格快捷键；保存前检测冲突，注册失败时恢复旧设置。
- 设置保存在当前用户本地应用数据目录，不写入项目目录。

### 应用索引

- 索引当前用户和所有用户的开始菜单目录，以及当前用户和公共桌面。
- 收录 `.lnk`、`.url`、`.appref-ms` 和可直接启动的 `.exe` 项目。
- 启动后在后台构建内存索引，并监视相关目录变化；索引只保存必要元数据。
- 结果按名称前缀、名称包含、路径包含和历史使用频率排序。

### 文件搜索

- 使用 Windows Search 系统索引查询文件，避免递归扫描磁盘。
- 查询失败、服务未启用或位置未被系统索引时，应用搜索仍可正常使用，并在结果区给出非阻塞提示。
- 输入至少两个字符后才触发文件查询；查询设置短超时，并限制返回数量，保证输入响应。
- 第一版不提供文件内容全文检索，只按文件名和路径检索。

### 启动与历史

- 使用系统默认关联程序打开文件、文件夹、快捷方式和网址。
- 最近使用记录写入用户本地应用数据目录，仅保存规范化路径、启动次数和最后启动时间。
- 历史文件损坏时忽略并重新创建，不阻止程序启动。

### 托盘与单实例

- 程序常驻通知区域，菜单提供“显示”“开机启动”“关于”和“退出”。
- 通过命名互斥体保证单实例；再次启动时唤起已有实例。
- 开机启动使用当前用户注册表项，可随时关闭，不需要管理员权限。

## 代码结构

- `src/Program.cs`：入口、单实例和未处理异常保护。
- `src/NativeMethods.cs`：Win32 API 声明与安全封装。
- `src/SearchWindow.cs`：窗口布局、快捷键处理和结果交互。
- `src/AppGridWindow.cs`：组合/全屏应用网格布局、分页和键盘导航。
- `src/GlassEffects.cs`：Windows 玻璃背板、圆角和兼容性回退。
- `src/AppIndex.cs`：应用与快捷方式索引。
- `src/WindowsSearch.cs`：Windows Search 查询适配器。
- `src/SearchEngine.cs`：合并、去重与排序。
- `src/Models.cs`：搜索结果和历史模型。
- `src/SettingsStore.cs`：设置与历史的本地持久化。
- `src/SettingsWindow.cs`：显示模式、快捷键和启动选项。
- `src/TrayApplicationContext.cs`：托盘菜单、生命周期和快捷键注册。
- `build.ps1`：零依赖构建脚本。
- `run.ps1`：构建并启动开发版本。
- `README.md`：使用、构建、限制和故障排查。

## 性能边界

- 空闲状态不轮询，CPU 使用率应接近 0%。
- 启动后应用索引在后台完成，UI 不被阻塞。
- 输入处理使用防抖与取消机制，过期文件查询结果不得覆盖新查询。
- 默认最多显示 8 条结果，限制图标缓存大小。
- 应用网格只加载当前页及相邻页图标，图标缓存设置固定上限。
- 不维护全盘自建数据库，依赖 Windows Search 已有索引控制内存和磁盘占用。

## 错误处理

- 全局快捷键冲突、Windows Search 不可用、快捷方式损坏和启动目标失败均单独处理。
- 可恢复错误显示为短提示，不弹出连续模态对话框。
- 严重启动错误写入本地日志并显示一次错误说明。

## 验证标准

- 构建脚本在当前电脑上无需下载依赖即可生成可运行的 `.exe`。
- `Alt + Space` 可在其他应用前台时唤起窗口。
- 可搜索并启动至少开始菜单和桌面中的常见应用。
- 组合模式下，空查询可显示应用网格，输入后可切换到搜索结果。
- 分离模式下，搜索框和全屏应用网格可分别通过快捷键打开。
- 设置修改显示模式后无需重启即可生效，快捷键冲突不会破坏原有配置。
- Windows 11 上启用系统玻璃材质；玻璃 API 不可用时界面仍可正常显示和操作。
- Windows Search 可用时，可按文件名搜索并打开本机文件。
- 上下键、Enter 和 Esc 行为正确。
- 重复启动不会产生第二个后台进程。
- 退出后全局快捷键被释放。
- 空闲一分钟内无持续 CPU 活动，内存占用保持稳定。

## 第一版范围外

- 管理员权限目录的强制扫描。
